## Scope

Spelling is the encoding counterpart to Phonics decoding. Expect Mama to correlate spelling errors strongly with Phonics confidence — if a child is Ready on Phonics but Intervention on Spelling, that's usually a motor/memory issue, not a phonological one. Flag that mismatch pattern in Specialist Notes.
